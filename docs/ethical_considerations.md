## 1. ETHICAL RESEARCH PRINCIPLES
This research adheres to the ethical guidelines established by KIU University and the IEEE Computer Society Code of Ethics.

### Data Privacy & Synthetic Modeling
- All dataset instances were synthesized or derived from anonymized public benchmark schemas (BoT-IoT).
- No actual private network traffic or sensitive personally identifiable information (PII) was sniffed or processed.

### Security Testing Integrity
- Attack simulations (DoS, DDoS, Mirai scans) were conducted strictly within isolated synthetic environments.
- No malicious payloads were transmitted over live production networks or public infrastructures.

## 2. DUAL-USE & RESPONSIBLE DISCLOSURE
The intrusion detection system developed in this project is strictly defensive software designed to protect IoT edge devices against cyber threats. 
- Signature rules and feature logic are published for defensive academic evaluation.
- No offensive exploit code or weaponized payloads are included in this repository.
